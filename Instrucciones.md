# PASOS A SEGUIR
1. Realizar las conexiones como se indica en el apartado de 'Conexiones'
2. Conectar el Arduino a la PC
3. Seleccionar el pueto donde está conectado el Arduino
4. Cargar el código
5. En la parte de Processing, ejecutar una vez para ver en la consola los puertos disponibles
6. Dentro de setup(), en la LINEA 16 del código, colocar el número que corresponda al mismo puerto que usó para cargar el código a Arduino
7. Ejecutar normalmente

# Proyecto de Entorno Grafico 
Alumno: Iannizzotto Leonel - 53167

Se basa en una interfaz gráfica de control de ENTRADA/SALIDA de Arduino, programada en Processing, que envia informacion por el puerto serial de la pc para intercomunicar Arduino y Processing.
* Los leds del Arduino se encienden mediante un pulso del mouse en el entorno grafico de Processing
* Al pulsar los botones de la parte de Arduino, se ve reflejado en pantalla cual boton está siendo presionado
